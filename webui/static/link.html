年齢確認(CCV) を Instagram / Facebook 連携で解除

muse の ccv_required はクレジットカードの他に、Meta の SNS アカウント連携でも解除できます。 デビットカードしか無い場合はこちらが有効です。このページは WebUI 本体 の補助画面です。
手順: 対象の「連携を開始」→ 表示された 承認する ボタンで Meta にログインして承認 → このページが自動で完了を検知して解除します（数十秒かかる場合があります）。
1 アカウントにつき 1 回の承認が必要です。ブラウザの Meta セッションが残っていれば 2 件目以降は数クリックで済みます。
承認 URL の寿命は実測で約 17 分です。 切れたら「URL 出し直す」で新しい URL を出せます（Muse 側の承認試行は作り直されます）。
連携が「使用不可」と判定された場合 (use_credit_card) は、そのアカウントでは SNS 連携が使えないので、 クレジットカードでの解除に切り替えてください。

進行中

まとめて処理する場合は「全部タブで開く」→ 開いたタブで順に 「許可」/「続行」 を押していくだけです。 承認は数十秒でこのページに反映され、行の状態が continue に変わります。 URL が切れたら「全部の URL を出す直す」を押してから、また「全部タブで開く」で続けられます。

年齢確認が未解除のアカウント

連携が済んだアカウントは自動で一覧から外れます。
